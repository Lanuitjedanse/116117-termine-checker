# Setup

1. Register on https://pushover.net/
2. set these env variables:

- `ETERM_URL` e.g. https://www.116117-termine.de/termin/suchen/1234-PMMQ-HF8K/12014/W983
- `PUSHOVER_TOKEN`
- `PUSHOVER_USER`

3. Activate the cron job in the file .github/workflows/check.yml
4. Add your github e-mail address to .github/workflows/check.yml
